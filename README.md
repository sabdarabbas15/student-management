# Flask Login System (PostgreSQL)

This is a simple web application built using Flask.

## Features
- User Registration
- User Login
- Password stored in database
- PostgreSQL database integration

## Tech Stack
- Python
- Flask
- PostgreSQL
- HTML/CSS

## How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run app:
   python app.py
